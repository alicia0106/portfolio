# CV Web — Martha A Herrera G

Sitio personal de una sola página, bilingüe (español/inglés), creado con HTML, CSS y JavaScript vanilla para publicarse en GitHub Pages.

## Archivos
- `index.html`: contenido y estructura.
- `style.css`: diseño responsive.
- `script.js`: selector de idioma.
- `assets/profile.jpg`: fotografía de perfil.
- `assets/CV_Herrera.pdf`: CV descargable.

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a la raíz del repositorio (no la carpeta contenedora `cv_portfolio`).
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
5. Espera a que GitHub Pages publique el sitio.

No se necesita un tema Jekyll ni un proceso de compilación. Si el repositorio ya tiene un `_config.yml`, puede permanecer ahí; esta página estática no depende de él.

## Personalización
- Cambia la foto reemplazando `assets/profile.jpg` por otra imagen con el mismo nombre.
- Reemplaza el PDF en `assets/CV_Herrera.pdf` para actualizar la descarga.
- Edita textos y datos de contacto directamente en `index.html`.
- Los textos bilingües usan los atributos `data-es` y `data-en`.
